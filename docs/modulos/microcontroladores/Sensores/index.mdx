Esta lista cobre **todos os sensores do inventário**, tenham ou não sido comprados ainda. Cada exercício usa **no máximo dois sensores**, e os atuadores são incluídos quando necessários. A lista começa com chaves e sensores digitais, passa pelos analógicos, sensores de distância, temperatura e ambientais, e termina com displays, energia e atuadores. No fim há uma seção com os C.Is e transistores que ainda não tinham exercício.

## 🛠 Requisitos e Materiais

- **ESP32 DEVKIT** (estoque: 5) e cabo USB
- **Arduino IDE** ou **PlatformIO** com o pacote *esp32 by Espressif* (versão 3.x)
- Protoboard, jumpers, resistores e LEDs (estoque alto)
- Multímetro para conferir tensões antes de ligar qualquer módulo

:::note
**Legenda de estoque.** ✅ (quantidade, ideal X) indica item que já está no laboratório. 🛒 (ideal X) indica item que ainda precisa ser comprado. Itens com quantidade 0 aparecem como 🛒.
:::

:::warning
**Tensão lógica.** O ESP32 aceita no máximo 3,3 V nos pinos de entrada. Vários módulos (HC-SR04, alguns displays, o RFID RC522 e o AS608) funcionam em 5 V. Use divisor de tensão ou conversor de nível lógico antes de ligar esses sinais aos pinos do ESP32.
:::

:::danger
**Pinos.** Use apenas os pinos GPIO 32 a 36 e 39 como entradas analógicas, pois o ADC2 não funciona com WiFi ligado. Evite GPIO 0, 2, 12 e 15 para cargas, pois são pinos de inicialização.
:::

### Exercício 1: Sensor de toque capacitivo

**Objetivo:** ler um toque sem contato mecânico com o módulo TTP223B e comparar com o sensor de toque KY-036.

**Materiais:** sensor TTP223B ✅ (2, ideal 2), sensor KY-036 ✅ (1, ideal 0), LED vermelho ✅ (45, ideal 20).

**Roteiro:**

1. Ligue o TTP223B ao GPIO 13 e o KY-036 ao GPIO 14.
2. Acenda um LED a cada toque detectado por cada sensor.
3. Compare a sensibilidade dos dois módulos.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int TOQUE_A = 13, TOQUE_B = 14, LED = 26;

void setup() {
  Serial.begin(115200);
  pinMode(TOQUE_A, INPUT);
  pinMode(TOQUE_B, INPUT);
  pinMode(LED, OUTPUT);
}

void loop() {
  bool a = digitalRead(TOQUE_A) == HIGH;
  bool b = digitalRead(TOQUE_B) == LOW;   // KY-036 costuma ser ativo em LOW
  digitalWrite(LED, a || b);
  Serial.printf("A=%d B=%d\n", a, b);
  delay(50);
}
```

O TTP223B sai em HIGH quando há toque. Já o KY-036 tem saída que depende do ajuste do módulo, por isso confira o nível no monitor serial antes de depender dele.

</details>

### Exercício 2: Detecção de chama e alarme sonoro

**Objetivo:** detectar chama com o sensor KY-026 e acionar um buzzer ativo.

**Materiais:** sensor de chama KY-026 ✅ (1, ideal 0), buzzer ativo ✅ (8, ideal 10).

**Roteiro:**

1. Ligue a saída DO do KY-026 ao GPIO 27 e o buzzer ao GPIO 25.
2. Quando a chama for detectada, ligue o buzzer.
3. Teste aproximando um isqueiro de forma segura, à distância.

:::warning
Não exponha o sensor a chamas reais de forma próxima. Use um isqueiro apenas à distância e nunca deixe o teste sem supervisão.
:::

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int CHAMA = 27, BUZZER = 25;

void setup() {
  pinMode(CHAMA, INPUT);
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  bool detectou = digitalRead(CHAMA) == LOW;   // saída ativa em LOW
  digitalWrite(BUZZER, detectou);
}
```

Muitos módulos de chama têm um potenciômetro de sensibilidade. Ajuste-o até o sensor reagir apenas à chama, e não à luz ambiente.

### Exercício 4: Vibração e batida

**Objetivo:** detectar vibrações com os sensores KY-002 e KY-031, e contar eventos.

**Materiais:** sensor KY-002 ✅ (1, ideal 1), sensor KY-031 ✅ (1, ideal 1).

**Roteiro:**

1. Ligue o KY-002 ao GPIO 18 e o KY-031 ao GPIO 19.
2. Use uma interrupção para contar cada vibração detectada.
3. Bata sobre uma mesa e observe a contagem no monitor serial.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int VIB_A = 18, VIB_B = 19;
volatile unsigned long contA = 0, contB = 0;

void IRAM_ATTR aoVibrarA() { contA++; }
void IRAM_ATTR aoVibrarB() { contB++; }

void setup() {
  Serial.begin(115200);
  pinMode(VIB_A, INPUT);
  pinMode(VIB_B, INPUT);
  attachInterrupt(VIB_A, aoVibrarA, RISING);
  attachInterrupt(VIB_B, aoVibrarB, RISING);
}

void loop() {
  Serial.printf("A=%lu B=%lu\n", contA, contB);
  delay(1000);
}
```

Como a interrupção pode disparar várias vezes com um único impacto, use o filtro de tempo do exercício 2 do submódulo de Interrupções de Hardware.

</details>

### Exercício 5: Contato magnético e chave de fim de curso

**Objetivo:** usar o sensor de inclinação de mercúrio KY-027 e uma chave de fim de curso como detectores de posição mecânica.

**Materiais:** sensor KY-027 ✅ (2, ideal 0), chave de fim de curso ✅ (5, ideal 5).

**Roteiro:**

1. Ligue o KY-027 ao GPIO 16 e a chave de fim de curso ao GPIO 17, ambos com pull-up.
2. Imprima o estado de cada um quando houver mudança.
3. Compare o comportamento da chave mecânica com o do sensor de mercúrio.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int MERC = 16, FIM = 17;
int antesM = -1, antesF = -1;

void setup() {
  Serial.begin(115200);
  pinMode(MERC, INPUT_PULLUP);
  pinMode(FIM, INPUT_PULLUP);
}

void loop() {
  int m = digitalRead(MERC), f = digitalRead(FIM);
  if (m != antesM || f != antesF) {
    Serial.printf("Mercurio=%d Fim=%d\n", m, f);
    antesM = m; antesF = f;
  }
  delay(20);
}
```

A chave de fim de curso é normalmente fechada ou aberta conforme a ligação. Teste os dois estados antes de definir a lógica.

</details>

### Exercício 6: Sensores reed (contato magnético)

**Objetivo:** detectar a presença de um ímã com os sensores reed KY-025 e KY-021.

**Materiais:** sensor KY-025 ✅ (1, ideal 5), sensor KY-021 ✅ (1, ideal 0), ímã de neodímio.

**Roteiro:**

1. Ligue o KY-025 ao GPIO 19 e o KY-021 ao GPIO 23, ambos com pull-up.
2. Aproxime o ímã de cada sensor e observe a mudança de nível.
3. Use o sensor como porta: acenda um LED quando a porta estiver aberta.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int REED_A = 19, REED_B = 23, LED = 26;

void setup() {
  pinMode(REED_A, INPUT_PULLUP);
  pinMode(REED_B, INPUT_PULLUP);
  pinMode(LED, OUTPUT);
}

void loop() {
  bool imaA = digitalRead(REED_A) == LOW;   // reed fecha com o ímã
  bool imaB = digitalRead(REED_B) == LOW;
  digitalWrite(LED, !(imaA && imaB));       // LED acende se qualquer porta abrir
}
```

O reed é um contato de vidro dentro de um tubo. Ele é simples e confiável, mas responde apenas à presença do ímã, sem medir a distância.

</details>

### Exercício 10: Encoders rotativos

**Objetivo:** contar pulsos de rotação com os encoders KY-040 e HW-040, e tratar o efeito de tremor (bounce) dos contatos.

**Materiais:** encoder KY-040 ✅ (1, ideal 5), sensor de rotação HW-040 ✅ (1, ideal 3).

**Roteiro:**

1. Ligue o canal CLK do KY-040 ao GPIO 18, o DT ao GPIO 19 e o botão ao GPIO 23.
2. Ligue o HW-040 ao GPIO 32 (CLK) e GPIO 33 (DT).
3. Conte os pulsos em cada direção e imprima a posição.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int KY_CLK = 18, KY_DT = 19;
volatile long posicao = 0;
int ultimoClk;

void setup() {
  Serial.begin(115200);
  pinMode(KY_CLK, INPUT);
  pinMode(KY_DT, INPUT);
  ultimoClk = digitalRead(KY_CLK);
}

void loop() {
  int clk = digitalRead(KY_CLK);
  if (clk != ultimoClk && clk == HIGH) {
    posicao += (digitalRead(KY_DT) != clk) ? 1 : -1;
    Serial.println(posicao);
  }
  ultimoClk = clk;
}
```

Para contagem confiável em alta velocidade, use interrupções (exercício 4 do submódulo de Interrupções de Hardware). O HW-040 segue a mesma lógica de quadratura.

</details>

## Parte 2: Sensores analógicos e de luz

### Exercício 11: Potenciômetros lineares e logarítmicos

**Objetivo:** comparar a resposta de um potenciômetro linear e de um logarítmico lidos pelo conversor analógico-digital.

**Materiais:** potenciômetro linear B10KΩ ✅ (9, ideal 10), potenciômetro logarítmico A10KΩ ✅ (8, ideal 5).

**Roteiro:**

1. Ligue o terminal central do B10KΩ ao GPIO 32 e o do A10KΩ ao GPIO 33. Os extremos vão para 3,3 V e GND.
2. Leia os dois valores e imprima em porcentagem.
3. Gire os dois potenciômetros e compare como a leitura varia ao longo do curso.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int LIN = 32, LOG = 33;

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);   // 0 a 4095
}

void loop() {
  float linear = analogRead(LIN) * 100.0 / 4095.0;
  float logaritmico = analogRead(LOG) * 100.0 / 4095.0;
  Serial.printf("Linear=%.1f%%  Log=%.1f%%\n", linear, logaritmico);
  delay(200);
}
```

O potenciômetro logarítmico varia o valor de forma não proporcional ao giro, e é usado em controles de volume. O linear varia de forma proporcional.

</details>

### Exercício 12: Fotorresistores (LDR) grande e pequeno

**Objetivo:** medir a luminosidade com dois LDRs de tamanhos diferentes, e comparar a faixa de resposta de cada um.

**Materiais:** LDR grande ✅ (22, ideal 5), LDR pequeno ✅ (29, ideal 10), resistores de 10KΩ ✅ (111, ideal 30) × 2.

**Roteiro:**

1. Monte um divisor de tensão para cada LDR com resistor de 10KΩ, e ligue o ponto médio ao GPIO 32 e ao GPIO 33.
2. Cubra os sensores com a mão e exponha-os à luz de uma lâmpada, e registre as leituras.
3. Calcule a resistência do LDR a partir da tensão lida.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int LDR_G = 32, LDR_P = 33;
const float R_FIXO = 10000.0;

void setup() {
  Serial.begin(115200);
}

void loop() {
  for (int pino : {LDR_G, LDR_P}) {
    int leitura = analogRead(pino);
    float tensao = leitura * 3.3 / 4095.0;
    float r = R_FIXO * (3.3 - tensao) / tensao;   // LDR ligado ao 3,3 V
    Serial.printf("Pino %d: %d  R=%.0f ohm\n", pino, leitura, r);
  }
  delay(500);
}
```

Com pouca luz, a resistência do LDR sobe muito. Por isso, a resposta não é linear, e use uma escala logarítmica se quiser comparar faixas de luz.

</details>

### Exercício 15: Sensor de cor TCS3200

**Objetivo:** identificar a cor de um objeto com o sensor TCS3200, lendo as frequências de cada filtro.

**Materiais:** sensor TCS3200 ✅ (3, ideal 3), objetos coloridos, LED branco ✅ (20, ideal 20) para iluminação.

**Roteiro:**

1. Ligue S0 e S1 ao GPIO 16 e 17, S2 e S3 ao GPIO 18 e 19, e a saída OUT ao GPIO 32.
2. Para cada filtro (vermelho, verde, azul), meça o período do sinal OUT com `pulseIn`.
3. Compare as leituras com os valores de referência de cada cor.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int S0 = 16, S1 = 17, S2 = 18, S3 = 19, OUT_COR = 32;

long lerFiltro(bool s2, bool s3) {
  digitalWrite(S2, s2);
  digitalWrite(S3, s3);
  return pulseIn(OUT_COR, LOW);
}

void setup() {
  Serial.begin(115200);
  pinMode(S0, OUTPUT); pinMode(S1, OUTPUT);
  pinMode(S2, OUTPUT); pinMode(S3, OUTPUT);
  pinMode(OUT_COR, INPUT);
  digitalWrite(S0, HIGH);   // escala 20%
  digitalWrite(S1, LOW);
}

void loop() {
  long r = lerFiltro(LOW, LOW);
  long g = lerFiltro(HIGH, HIGH);
  long b = lerFiltro(LOW, HIGH);
  Serial.printf("R=%ld G=%ld B=%ld\n", r, g, b);
  delay(500);
}
```

Valores menores de período indicam mais intensidade daquela cor. Calibre com um branco e um preto antes de comparar cores.

</details>

### Exercício 17: Semáforo e emissor de laser

**Objetivo:** montar um semáforo com o módulo de semáforo e controlar um emissor de laser KY-008 como atuador.

**Materiais:** módulo semáforo ✅ (1, ideal 0), emissor de laser KY-008 ✅ (1, ideal 5), resistores de 220Ω ✅ (127, ideal 30).

**Roteiro:**

1. Ligue o vermelho, o amarelo e o verde do semáforo aos GPIO 25, 26 e 27.
2. Faça o ciclo verde, amarelo, vermelho com o tempo de cada cor definido em constantes.
3. Ligue o laser ao GPIO 14 e acenda-o somente quando o semáforo estiver vermelho.

:::danger
Nunca aponte um laser para os olhos, nem para outras pessoas. Use apenas módulos de baixa potência e mantenha o feixe abaixo da altura dos olhos.
:::

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int VERM = 25, AMAR = 26, VERDE = 27, LASER = 14;

void setup() {
  pinMode(VERM, OUTPUT); pinMode(AMAR, OUTPUT);
  pinMode(VERDE, OUTPUT); pinMode(LASER, OUTPUT);
}
```

**Roteiro:**

2. Monte um divisor com o NTC e o resistor de 10KΩ, e ligue o ponto médio ao GPIO 32.
3. Calcule a resistência do NTC e a temperatura pela equação beta, e compare com o SHT31.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp

#include <Adafruit_SHT31.h>

  Serial.begin(115200);
  Wire.begin(21, 22);
  sht.begin(0x44);
```

A AT24C256 está com quantidade 0. Este exercício mostra a montagem para quando ela for comprada. Os endereços de escrita têm 2 bytes, pois a memória tem 32 KB.
:::

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <Wire.h>

const uint8_t EEPROM_END = 0x50;

void escreverByte(uint16_t endereco, uint8_t valor) {
  Wire.beginTransmission(EEPROM_END);
  Wire.write(endereco >> 8);
  Wire.write(endereco & 0xFF);
  Wire.write(valor);
  Wire.endTransmission();
  delay(5);   // tempo de escrita interna
}

uint8_t lerByte(uint16_t endereco) {
  Wire.beginTransmission(EEPROM_END);
  Wire.write(endereco >> 8);
  Wire.write(endereco & 0xFF);
  Wire.endTransmission();
  Wire.requestFrom(EEPROM_END, (uint8_t)1);
  return Wire.read();
}

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);
  uint8_t cont = lerByte(0) + 1;
  escreverByte(0, cont);
  Serial.printf("Inicializacoes: %d\n", cont);
}

void loop() {}
```

A EEPROM tem vida útil limitada por número de escritas, então evite gravar a cada ciclo do loop. Grave somente quando o valor mudar.

</details>

### Exercício 66: Par complementar NPN e PNP com BC546 e BC557

**Objetivo:** montar um interruptor com um transistor NPN e um PNP complementares, acionados pelo ESP32.

**Materiais:** transistor BC546 ✅ (9, ideal 20), transistor BC557 ✅ (22, ideal 10), LED verde ✅ (40), resistores de 1KΩ ✅ (199) e 10KΩ ✅ (111).

**Roteiro:**

1. Monte o NPN com a base no GPIO 25 por 1KΩ, o coletor no LED e o emissor no GND.
2. Monte o PNP com o emissor em 3,3 V, a base no GPIO 26 por 1KΩ, e o coletor no segundo LED.
3. Alterne os dois LEDs e observe que o PNP acende com nível baixo.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int BASE_NPN = 25, BASE_PNP = 26;

void setup() {
  pinMode(BASE_NPN, OUTPUT);
  pinMode(BASE_PNP, OUTPUT);
}

void loop() {
  digitalWrite(BASE_NPN, HIGH);   // NPN conduz com base em nível alto
  digitalWrite(BASE_PNP, HIGH);   // PNP fica desligado com base em nível alto
  delay(1000);
  digitalWrite(BASE_NPN, LOW);
  digitalWrite(BASE_PNP, LOW);    // PNP conduz com base em nível baixo
  delay(1000);
}
```

O NPN conduz quando a base recebe corrente positiva, e o PNP conduz quando a base é puxada para baixo. Esse par é a base de muitos circuitos de potência em push-pull.

</details>

### Exercício 67: Darlington para cargas de corrente alta

**Objetivo:** acionar uma carga de corrente mais alta com o par Darlington TIP41 (NPN) e TIP42 (PNP), que tem ganho de corrente muito maior que um transistor simples.

**Materiais:** transistor TIP41 ✅ (3, ideal 5), transistor TIP42 ✅ (2, ideal 5), motor DC 5V ✅ (6, ideal 5), diodo 1N4007 ✅ (41), resistor de 1KΩ ✅ (199).

**Roteiro:**

1. Ligue o TIP41 como interruptor do motor, com a base no GPIO 25 por 1KΩ, e o emissor no GND.
2. Coloque o diodo 1N4007 em paralelo com o motor, no sentido de roda livre.
3. Troque o TIP41 pelo TIP42 com ligação complementar, e compare a corrente de base necessária.

:::warning
O TIP41 precisa de dissipador em correntes altas. Não ultrapasse a corrente do datasheet, e confira a polaridade do diodo antes de ligar o motor.
:::

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
const int BASE = 25;

void setup() {
  pinMode(BASE, OUTPUT);
}

void loop() {
  digitalWrite(BASE, HIGH);   // motor ligado
  delay(3000);
  digitalWrite(BASE, LOW);    // motor desligado
  delay(3000);
}
```

O par Darlington tem queda de tensão maior, de cerca de 1,5 V a 2 V, o que aquece mais que um MOSFET. Para cargas grandes, prefira um MOSFET do submódulo de Sinais e PWM.

</details>

### Exercício 69: Transistores de sinal PN2907 e C33725

**Objetivo:** usar os transistores de sinal PN2907 (PNP) e C33725 (NPN) como interruptores para cargas pequenas, como LEDs.

**Materiais:** transistor PN2907 ✅ (11, ideal 10), transistor C33725 ✅ (12, ideal 10), LEDs ✅ (45), resistores de 1KΩ ✅ (199).

**Roteiro:**

1. Monte o C33725 como interruptor de um LED, com a base no GPIO 25 por 1KΩ.
2. Monte o PN2907 como interruptor de outro LED, com o emissor em 3,3 V e a base no GPIO 26.

```cpp
const int BASE_NPN = 25, BASE_PNP = 26;
```

## 📦 Itens sem exercício neste submódulo

Os itens abaixo estão no inventário, mas não têm exercício próprio, pelo motivo indicado.

- **ST-LINK** (gravador): é específico para microcontroladores STM32, e não grava o ESP32. Use-o apenas em outro projeto.
- **Arduino Uno, Nano, Leonardo e Mega**: são placas de outra família. Os exercícios usam o ESP32, mas a lógica dos componentes é a mesma.
- **Raspberry Pi 2 e 3, e Raspberry Pi Pico**: são plataformas diferentes, com sistemas próprios. O Pico usa a linguagem MicroPython ou C/C++ com SDK próprio.
- **ESP32 S3** (estoque 0): tem a mesma família do DEVKIT, e os exercícios funcionam com pequenos ajustes de pinos, conforme o módulo.
- **BIT DOG LAB**: o inventário não traz o modelo nem o datasheet. Confirme a função do módulo antes de criar um exercício.
- **Conector Tipo C** (estoque 0) e **borne de 4 pinos** (estoque 0): cobertos pelo exercício 70, quando comprados.
- **Módulo ESP32 com tela e touch** (estoque 1): usado no exercício 48 como referência de display.
