### Exercício 1: Dia da Semana

**Objetivo:** Leia um número de 1 a 7 e mostre o dia da semana correspondente, considerando 1 como domingo e 7 como sábado.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    int dia;
    cout << "Digite um número de 1 a 7: ";
    cin >> dia;

    switch (dia)
    {
    case 1:
        cout << "Domingo";
        break;
    case 2:
        cout << "Segunda-feira";
        break;
    case 3:
        cout << "Terça-feira";
        break;
    case 4:
        cout << "Quarta-feira";
        break;
    case 5:
        cout << "Quinta-feira";
        break;
    case 6:
        cout << "Sexta-feira";
        break;
    case 7:
        cout << "Sábado";
        break;
    default:
        cout << "Dia inválido";
    }
}
```

</details>

### Exercício 4: Calculadora Básica

**Objetivo:** Leia dois números reais e um operador aritmético (`+`, `-`, `*` ou `/`).

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    double primeiro, segundo;
    char operador;

    cout << "Digite dois números e o operador (+, -, * ou /): ";
    cin >> primeiro >> segundo >> operador;

    switch (operador)
    {
    case '+':
        cout << primeiro + segundo;
        break;
    case '-':
        cout << primeiro - segundo;
        break;
    case '*':
        cout << primeiro * segundo;
        break;
    case '/':
        if (segundo == 0)
            cout << "Não é possível dividir por zero";
        else
            cout << primeiro / segundo;
        break;
    default:
        cout << "Operador inválido";
    }
}
```

</details>

### Exercício 5: Conversão de Temperatura

**Objetivo:** Leia uma temperatura e uma opção de conversão: `C` para Celsius para Fahrenheit ou `F` para Fahrenheit para Celsius.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    double temperatura, convertida;
    char opcao;

    cout << "Digite a temperatura e a opção (C ou F): ";
    cin >> temperatura >> opcao;

    switch (opcao)
    {
    case 'C':
    case 'c':
        convertida = temperatura * 9 / 5 + 32;
        cout << convertida << " °F";
        break;
    case 'F':
    case 'f':
        convertida = (temperatura - 32) * 5 / 9;
        cout << convertida << " °C";
        break;
    default:
        cout << "Opção inválida";
    }
}
```

</details>

### Exercício 8: Operação com Figuras Geométricas

**Objetivo:** Leia o código de uma figura geométrica e suas medidas. Calcule a área de um quadrado, retângulo, triângulo ou círculo conforme a opção escolhida.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    int codigo;
    double lado, base, altura, comprimento, largura, raio, area;

    cout << "1 - Quadrado\n2 - Retângulo\n3 - Triângulo\n4 - Círculo\n";
    cout << "Escolha uma figura: ";
    cin >> codigo;

    switch (codigo)
    {
    case 1:
        cout << "Digite o lado: ";
        cin >> lado;
        area = lado * lado;
        break;
    case 2:
        cout << "Digite o comprimento e a largura: ";
        cin >> comprimento >> largura;
        area = comprimento * largura;
        break;
    case 3:
        cout << "Digite a base e a altura: ";
        cin >> base >> altura;
        area = base * altura / 2;
        break;
    case 4:
        cout << "Digite o raio: ";
        cin >> raio;
        area = 3.14159 * raio * raio;
        break;
    default:
        cout << "Figura inválida";
        return 0;
    }

    cout << "Área: " << area;
}
```

</details>

### Exercício 9: Sistema Bancário

**Objetivo:** Leia o saldo de uma conta, uma operação e o valor movimentado. As operações devem permitir depósito, saque e consulta de saldo.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    double saldo, valor;
    int operacao;

    cout << "Digite o saldo inicial: ";
    cin >> saldo;
    cout << "1 - Depósito\n2 - Saque\n3 - Consultar saldo\n";
    cout << "Escolha uma operação: ";
    cin >> operacao;

    switch (operacao)
    {
    case 1:
        cout << "Digite o valor do depósito: ";
        cin >> valor;
        if (valor <= 0)
            cout << "Valor inválido";
        else
        {
            saldo += valor;
            cout << "Saldo atual: R$" << saldo;
        }
        break;
    case 2:
        cout << "Digite o valor do saque: ";
        cin >> valor;
        if (valor <= 0)
            cout << "Valor inválido";
        else if (valor > saldo)
            cout << "Saldo insuficiente";
        else
        {
            saldo -= valor;
            cout << "Saldo atual: R$" << saldo;
        }
        break;
    case 3:
        cout << "Saldo atual: R$" << saldo;
        break;
    default:
        cout << "Operação inválida";
    }
}
```

</details>

### Exercício 10: Quiz de Conhecimentos Gerais

**Objetivo:** Crie um quiz com pelo menos cinco perguntas de múltipla escolha. Mostre cada pergunta, leia a alternativa escolhida e use `switch case` para verificar a resposta.

<details>
<summary>💡 Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    int resposta, pontos = 0;

    cout << "1) Qual linguagem estamos estudando?\n";
    cout << "1 - C++  2 - Java  3 - Python  4 - Ruby\n";
    cin >> resposta;
    switch (resposta)
    {
    case 1:
        cout << "Correta!\n";
        pontos++;
        break;
    default:
        cout << "Incorreta!\n";
    }

    cout << "2) Quanto é 2 + 2?\n";
    cout << "1 - 3  2 - 4  3 - 5  4 - 6\n";
    cin >> resposta;
    switch (resposta)
    {
    case 2:
        cout << "Correta!\n";
        pontos++;
        break;
    default:
        cout << "Incorreta!\n";
    }

    cout << "3) Qual estrutura seleciona uma opção?\n";
    cout << "1 - if  2 - for  3 - switch  4 - while\n";
    cin >> resposta;
    switch (resposta)
    {
    case 3:
        cout << "Correta!\n";
        pontos++;
        break;
    default:
        cout << "Incorreta!\n";
    }

    cout << "4) Quantos bits há em um byte?\n";
    cout << "1 - 4  2 - 8  3 - 16  4 - 32\n";
    cin >> resposta;
    switch (resposta)
    {
    case 2:
        cout << "Correta!\n";
        pontos++;
        break;
    default:
        cout << "Incorreta!\n";
    }

    cout << "5) Qual símbolo inicia um comentário de uma linha em C++?\n";
    cout << "1 - //  2 - ##  3 - %%  4 - **\n";
    cin >> resposta;
    switch (resposta)
    {
    case 1:
        cout << "Correta!\n";
        pontos++;
        break;
    default:
        cout << "Incorreta!\n";
    }

    cout << "Pontuação final: " << pontos << " de 5";
}
```

</details>
