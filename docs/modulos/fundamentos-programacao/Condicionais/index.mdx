# Introdução aos Exercícios de Condicionais

Bem-vindo à seção de exercícios sobre estruturas condicionais!

## Como funcionam os exercícios

Cada atividade apresenta um objetivo e um gabarito com uma possível solução em C++. Tente resolver o exercício sozinho antes de consultar a resposta.

## O que você vai precisar

Para desenvolver e testar os programas, recomenda-se utilizar:

  * Um compilador C++, como:
    - [OnlineGDB](https://www.onlinegdb.com/online_c++_compiler)
    - [Programiz Online C++ Compiler](https://www.programiz.com/cpp-programming/online-compiler/)
  * Ou uma IDE ou editor de código instalado no computador.

## Sequência de estudos

É indicado seguir a sequência sugerida:

  1. [Condicionais simples (`if`)](./condicionais-if)
  2. [Condicionais compostas (`else if`)](./condicionais-else-if)
  3. [Condicionais compostas (`switch case`)](./condicionais-switch)

:::tip

Teste diferentes entradas e observe o comportamento do programa em cada situação.

Bons estudos e mãos à obra!

:::
