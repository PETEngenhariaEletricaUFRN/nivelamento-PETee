# Introdução aos Exercícios de Laços de Repetição

Bem-vindo à seção de exercícios sobre laços de repetição!

## Como funcionam os exercicios

Os exercícios estão organizados conforme a estrutura utilizada: for, while e do while. Tente resolver cada atividade antes de consultar o gabarito.

## O que você vai precisar

Um compilador C++17, como [OnlineGDB](https://www.onlinegdb.com/) ou [Programiz](https://www.programiz.com/cpp-programming/online-compiler/), e uma IDE ou editor de codigo.
