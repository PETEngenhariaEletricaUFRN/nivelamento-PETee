### Exercício 1: Contagem com do-while 

**Objetivo:** Crie um programa que mostre os números de 0 a 5, separados por espaços:

```text
0 1 2
```

<details>
<summary>Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    int valor = 0;

    do
    {
        cout << valor << " ";
        valor++;
    } while (valor < 6);
}
```

</details>

### Exercício 2: Média de idade com repetição 

**Objetivo:** Faça um programa que leia a idade de várias pessoas. Após cada idade, pergunte se o usuário deseja continuar. Quando o usuário decidir parar, mostre a quantidade de pessoas cadastradas e a média das idades.

<details>
<summary>Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    int idade, soma = 0, quantidade = 0;
    char continuar;

    do
    {
        cout << "Digite uma idade: ";
        cin >> idade;
        soma += idade;
        quantidade++;
        cout << "Deseja continuar? (S/N): ";
        cin >> continuar;
    } while (continuar == 'S' || continuar == 's');

    cout << "Quantidade de pessoas: " << quantidade << "\n";
    cout << "Media das idades: "
         << soma / static_cast<double>(quantidade);
}
```

</details>

### Exercício 3: Estatísticas de números com do-while 

**Objetivo:** Crie um programa que leia pelo menos um número inteiro por vez. Após cada leitura, pergunte se o usuário deseja continuar. Quando o usuário decidir parar, mostre:

- a) O somatório entre todos os valores
- b) Qual foi o menor valor digitado
- c) A média entre todos os valores
- d) Quantos valores são pares

<details>
<summary>Ver Resolução / Gabarito</summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    int valor, soma = 0, menor = 0, quantidade = 0, pares = 0;
    char continuar;

    do
    {
        cout << "Digite um numero inteiro: ";
        cin >> valor;
        if (quantidade == 0 || valor < menor)
            menor = valor;
        soma += valor;
        quantidade++;
        if (valor % 2 == 0)
            pares++;
        cout << "Deseja continuar? (S/N): ";
        cin >> continuar;
    } while (continuar == 'S' || continuar == 's');

    cout << "Soma: " << soma << "\n";
    cout << "Menor valor: " << menor << "\n";
    cout << "Media: "
         << soma / static_cast<double>(quantidade) << "\n";
    cout << "Quantidade de valores pares: " << pares;
}
```

</details>
