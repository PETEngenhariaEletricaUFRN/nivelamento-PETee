### Exercício 86: Exercício 86 (Básico)

**Objetivo:** Crie um programa que tenha uma função `void gerador()` que, quando chamada, mostre a mensagem `Olá, Mundo!` com algum componente visual (linhas).

**Enunciado e instruções:**

Crie um programa que tenha uma função `void gerador()` que, quando chamada, mostre a mensagem `Olá, Mundo!` com algum componente visual (linhas).

```
+-------=======------+
 Olá, Mundo!
+-------=======------+
```

:::tip Dica

Quebre o problema em etapas, teste casos simples e compile com `g++ -std=c++17 -Wall -Wextra`.

### Exercício 89: Exercício 89 (Básico)

**Objetivo:** Melhore a função `gerador()` para que o programador possa escolher uma entre três bordas:

**Enunciado e instruções:**

Melhore a função `gerador()` para que o programador possa escolher uma entre três bordas:

```
+-------=======------+   Borda 1
~~~~~~~~:::::::~~~~~~~   Borda 2
<<<<<<<<------->>>>>>>   Borda 3
```

Ex.: uma chamada válida seria `gerador("Estudando C++", 3, 2);`

```
~~~~~~~~:::::::~~~~~~~
 Estudando C++
 Estudando C++
 Estudando C++
~~~~~~~~:::::::~~~~~~~
```

Dica: explore **parâmetros com valor padrão** do C++ (ex.: `int repeticoes = 1, int borda = 1`) ou **sobrecarga de funções**.
