### Exercício 93: Exercício 93 (Básico)

**Objetivo:** Faça um programa que tenha uma função `void contador(int inicio, int fim, int incremento)`. O programa principal deve solicitar a digitação desses valores e passá-los à função, que vai mostrar a contagem na tela.

**Enunciado e instruções:**

Faça um programa que tenha uma função `void contador(int inicio, int fim, int incremento)`. O programa principal deve solicitar a digitação desses valores e passá-los à função, que vai mostrar a contagem na tela.
Ex.: para início = 4, fim = 20 e incremento = 3, `contador(4, 20, 3)` mostra:

```
4 >> 7 >> 10 >> 13 >> 16 >> 19 >> FIM
```

:::tip Dica

Quebre o problema em etapas, teste casos simples e compile com `g++ -std=c++17 -Wall -Wextra`.

:::

### Exercício 94: Exercício 94 (Desafio)

**Objetivo:** **[DESAFIO]** Desenvolva um programa que tenha uma função `void fibonacci(int termos)` que recebe um único valor inteiro como parâmetro, indicando quantos termos da sequência serão mostrados na tela.

**Enunciado e instruções:**

**[DESAFIO]** Desenvolva um programa que tenha uma função `void fibonacci(int termos)` que recebe um único valor inteiro como parâmetro, indicando quantos termos da sequência serão mostrados na tela.
Obs.: use os exercícios 70 e 75 para ajudar na solução.

```
fibonacci(5) -> 1 >> 1 >> 2 >> 3 >> 5 >> FIM
fibonacci(9) -> 1 >> 1 >> 2 >> 3 >> 5 >> 8 >> 13 >> 21 >> 34 >> FIM
```
