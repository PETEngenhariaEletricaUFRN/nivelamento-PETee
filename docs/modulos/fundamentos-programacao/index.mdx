# Fundamentos de Programação

Exercícios de algoritmos em C++, organizados por conceito e progressão de dificuldade.

## Convenções

- Use `#include <iostream>`, `<string>`, `<vector>`, `<cmath>`, `<iomanip>` e `<random>` conforme necessário.
- Leia números com `std::cin` e textos com espaços usando `std::getline`.
- Use `double` para números reais e ponto como separador decimal.
- Compile com `g++ -std=c++17 -Wall -Wextra programa.cpp -o programa`.
