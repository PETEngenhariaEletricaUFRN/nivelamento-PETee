# Fundamentos de Programação

Exercícios de algoritmos em C++, organizados por conceito e progressão de dificuldade.

Grande parte dos exercícios foram retirados do [arquivo de exercícios](https://www.cursoemvideo.com/wp-content/uploads/2019/08/exercicios-algoritmos.pdf) do curso de algoritmos na plataforma do curso em vídeo 

## Organização dos exercícios

| Submódulo | Exercícios |
| --- | --- |
| [Códigos com Lógica Simples](/docs/fundamentos-programacao/codigos-com-logica-simples) | sequências, entrada, saída e operações |
| [Condicionais](/docs/fundamentos-programacao/condicionais) | `if`, `else`, `else if`, `switch case` |
| [Laços de Repetição](/docs/fundamentos-programacao/lacos-de-repeticao) | `while`, `do while` e `for` |
| [Vetores](/docs/fundamentos-programacao/vetores) | vetores, arrays e ordenação |
| [Modularização](/docs/fundamentos-programacao/modularizacao) | procedimentos e funções |
| [Matrizes](/docs/fundamentos-programacao/matrizes) | Reservado para exercícios de matrizes |
| [Structs](/docs/fundamentos-programacao/structs) | Reservado para exercícios de estruturas |
| [Endereços de Memória](/docs/fundamentos-programacao/enderecos-de-memoria) | ponteiros e referências |
| [POO](/docs/fundamentos-programacao/poo) | Reservado para exercícios de orientação a objetos |
